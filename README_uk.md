# pplaneX — Якісний та числовий аналіз 2D автономних систем

**pplaneX** — це сучасний високопродуктивний інтерактивний десктопний застосунок, створений за допомогою Java 21 та JavaFX для якісного та числового аналізу двовимірних автономних систем звичайних диференціальних рівнянь (ЗДР) та планарних фазових портретів:

$$x' = \frac{dx}{dt} = f(x, y)$$
$$y' = \frac{dy}{dt} = g(x, y)$$

Натхненний класичним освітнім інструментом `pplane`, спочатку створеним Джоном К. Полкінгом (Університет Райса) для MATLAB, **pplaneX** було переписано з нуля для забезпечення плавної взаємодії з користувачем, адаптивного рендерингу в реальному часі, безперервного дослідження за допомогою масштабування/паноромування та універсальної кросплатформної підтримки (Linux, Windows та macOS).

## 📥 Встановлення та швидкий старт

**pplaneX** поширюється як автономний виконуваний JAR-файл і вимагає **Java 21 (LTS) або новішої версії**.

Якщо у вас не встановлено Java або вам потрібні покрокові інструкції для вашої операційної системи (Windows, macOS або Linux), зверніться до наших локалізованих посібників зі встановлення:

- 📖 **[Посібник зі встановлення (Українська)](INSTALL_uk.md)**

### Запуск застосунку

Після встановлення Java 21+ виконайте у своєму терміналі:

```bash
java -jar pplaneX.jar
```
