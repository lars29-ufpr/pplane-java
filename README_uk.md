# pplaneX — Якісний та чисельний аналіз 2D автономних систем

**pplaneX** — це сучасний, високопродуктивний інтерактивний настільний застосунок, створений за допомогою Java 21 та JavaFX для якісного та чисельного аналізу двовимірних автономних систем звичайних диференціальних рівнянь (ЗДР) і плоских фазових портретів:

$$x' = \frac{dx}{dt} = f(x, y)$$
$$y' = \frac{dy}{dt} = g(x, y)$$

Натхненний класичним освітнім інструментом `pplane`, спочатку створеним John C. Polking (Університет Райса) для MATLAB, **pplaneX** був перероблений з нуля, щоб запропонувати плавну взаємодію з користувачем, адаптивний рендеринг у реальному часі, безперервне дослідження за допомогою панорамування/масштабування та універсальну кросплатформну підтримку (Linux, Windows та macOS).

## 📥 Встановлення та швидкий старт

**pplaneX** розповсюджується як самостійний виконуваний файл JAR і вимагає **Java 21 (LTS) або новішої версії**.

Якщо у вас не встановлена Java або вам потрібен покроковий посібник для вашої операційної системи (Windows, macOS або Linux), перегляньте наші посібники зі встановлення:
- 🇺🇦 [Посібник зі встановлення (Українська)](INSTALL_uk.md)

### Запуск застосунку

Після встановлення Java 21+ запустіть з терміналу:

```bash
java -jar pplaneX.jar
```
