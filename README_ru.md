# pplaneX — Качественный и численный анализ автономных 2D систем

> 🌍 **Languages:** [English](README.md) | [Português](README.pt-BR.md) | [Español](README.es.md) | [Français](README_fr.md) | **Русский**

---

**pplaneX** — это современное интерактивное и высокопроизводительное настольное приложение, созданное на базе Java 21 и JavaFX для качественного и численного анализа двумерных автономных систем обыкновенных дифференциальных уравнений (ОДУ) и плоских фазовых портретов:

$$x' = \frac{dx}{dt} = f(x, y)$$
$$y' = \frac{dy}{dt} = g(x, y)$$

Вдохновленный классическим образовательным инструментом pplane, изначально созданным Джоном Ч. Полкингом (John C. Polking) (Университет Райса) для MATLAB, **pplaneX** был переписан с нуля, чтобы предложить плавное взаимодействие, рендеринг в реальном времени, непрерывную навигацию (панорамирование/масштабирование) и универсальную кроссплатформенную поддержку (Linux, Windows и macOS).

## 📥 Установка и быстрый старт

**pplaneX** распространяется как автономный исполняемый JAR-файл и требует **Java 21 (LTS) или новее**.

Если у вас не установлена Java или вам нужна пошаговая помощь, ознакомьтесь с нашими руководствами:
- 📖 [Руководство по установке (Русский)](INSTALL_ru.md)

### Запуск приложения

После установки Java 21+ выполните в терминале (используйте флаги ниже, если хотите принудительно выбрать язык):

    java -Duser.language=ru -jar pplaneX.jar

## 🚀 Основные возможности
- **Интерактивный рендеринг:** Векторные поля в реальном времени и итеративное построение орбит.
- **Высокоточное численное интегрирование:** Адаптивные методы Рунге-Кутты.
- **Качественный анализ:** Идентификация точек равновесия, вычисление матрицы Якоби и построение нуль-изоклин.
- **Встроенная галерея систем:** Классические модели биоматематики, эпидемиологии и осцилляторы.
- **Экспорт графики:** Чистый векторный SVG (идеально для LaTeX) и PNG в высоком разрешении.
