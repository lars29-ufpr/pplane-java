# pplaneX — Качественный и численный анализ двумерных автономных систем

**pplaneX** — это современное высокопроизводительное интерактивное десктопное приложение, созданное с использованием Java 21 и JavaFX для качественного и численного анализа двумерных автономных систем обыкновенных дифференциальных уравнений (ОДУ) и фазовых портретов на плоскости:

$$x' = \frac{dx}{dt} = f(x, y)$$
$$y' = \frac{dy}{dt} = g(x, y)$$

Вдохновленный классическим образовательным инструментом `pplane`, первоначально созданным Джоном К. Полкінгом (Университет Райса) для MATLAB, **pplaneX** был полностью переписан с нуля, чтобы обеспечить плавное взаимодействие с пользователем, адаптивный рендеринг в реальном времени, непрерывное исследование с масштабированием/прокруткой и универсальную кроссплатформенную поддержку (Linux, Windows и macOS).

## 📥 Установка и быстрый старт

**pplaneX** распространяется в виде автономного исполняемого JAR-файла и требует наличия **Java 21 (LTS) или новее**.

Если у вас не установлена Java или вам нужны пошаговые инструкции для вашей операционной системы (Windows, macOS или Linux), обратитесь к нашим локализованным руководствам по установке:

- 📖 **[Руководство по установке (Русский)](INSTALL_ru.md)**

### Запуск приложения

После установки Java 21+ выполните в терминале:

```bash
java -jar pplaneX.jar
```
