# Навчальний посібник з динамічних моделей (Фазова площина)
## pplaneX — Версія 1.2

Цей посібник містить канонічний каталог двовимірних ($2 \times 2$) систем звичайних диференціальних рівнянь, реалізованих у **pplaneX**. Кожна модель включає своє математичне формулювання, практичний посібник для дослідження на фазовій площині та класичні концептуальні посилання.

---

# I. Біоматематика та популяційна динаміка

---

### 1. Модель Хижак-Жертва (Лотка-Вольтерра)

#### Математичне формулювання та параметри
Класична модель Лотки-Вольтерри описує взаємодію хижацтва між двома видами в однорідному середовищі:

$$\frac{dx}{dt} = \alpha x - \beta x y = x(\alpha - \beta y)$$
$$\frac{dy}{dt} = \delta x y - \gamma y = y(\delta x - \gamma)$$

- **Змінні стану:**
  * $x(t) \ge 0$: Щільність популяції жертв.
  * $y(t) \ge 0$: Щільність популяції хижаків.

- **Типові параметри:**
  * $\alpha = 1.0$: Внутрішня швидкість росту жертв за відсутності хижаків.
  * $\beta = 0.5$: Частота хижацтва (відлов та споживання).
  * $\delta = 0.5$: Біологічна ефективність перетворення спожитих жертв на нових хижаків.
  * $\gamma = 1.0$: Рівень смертності хижаків на душу населення.

- **Точки рівноваги та інваріант:**
  * $(0, 0)$: Нестійке сідло.
  * $(x^*, y^*) = \left(\frac{\gamma}{\delta}, \frac{\alpha}{\beta}\right) = (2.0, 2.0)$: Лінійно нейтральний консервативний центр.

#### Практичний посібник для дослідження
1. **Нуль-ізокліни:** Зверніть увагу на ортогональні нуль-ізокліни: $\frac{dx}{dt} = 0 \implies x = 0$ або $y = 2.0$; $\frac{dy}{dt} = 0 \implies y = 0$ або $x = 2.0$.
2. **Замкнені орбіти:** Клікніть на початкові умови на різних відстанях від $(2.0, 2.0)$. Усі розв'язки утворюють неперіодичні замкнені цикли, що керуються збереженою енергією $V(x, y)$.

---

### 2. Конкуренція двох видів (Мюррей)

#### Математичне формулювання та параметри
Описує динаміку двох біологічних видів, що конкурують за одні й ті самі ніші або харчові ресурси:

$$\frac{dx}{dt} = r_1 x \left(1 - \frac{x}{K_1} - \alpha_{12} \frac{y}{K_1}\right)$$
$$\frac{dy}{dt} = r_2 y \left(1 - \frac{y}{K_2} - \alpha_{21} \frac{x}{K_2}\right)$$

- **Типові параметри:**
  * $r_1 = 1.0, r_2 = 1.0$: Внутрішні швидкості росту на душу населення.
  * $K_1 = 3.0, K_2 = 3.0$: Індивідуальна ємність середовища.
  * $\alpha_{12} = 0.5, \alpha_{21} = 0.7$: Коефіцієнти міжвидового пригнічення.

#### Практичний посібник для дослідження
1. **Басейни притягання:** Клікніть біля координатних осей і спостерігайте за збіжністю до стійкого співіснування.
2. **Конкурентне виключення:** Змініть параметри на $\alpha_{12} = 1.5$ та $\alpha_{21} = 1.3$, потім побудуйте сепаратриси, щоб візуалізувати розділений басейн.

---

### 3. Нейронна модель ФітцХ'ю-Нагумо

#### Математичне формулювання та параметри
Площинна редукція біофізичної моделі Ходжкіна-Хакслі для потенціалів дії:

$$\frac{dv}{dt} = v - \frac{v^3}{3} - w + I_{\text{ext}}$$
$$\frac{dw}{dt} = \epsilon (v + a - b w)$$

- **Типові параметри:**
  * $a = 0.7, b = 0.8$: Параметри кінетики відновлення.
  * $\epsilon = 0.08$: Розділення повільної/швидкої шкали часу.
  * $I_{\text{ext}} = 0.5$: Інжектований зовнішній стимулюючий струм.

---

### 4. Епідемія SIR (Кермак-МакКендрік)

#### Математичне формулювання та параметри
Епідеміологічна модель передачі патогенів зі стійким імунітетом ($S + I + R = 1$):

$$\frac{dS}{dt} = -\beta S I$$
$$\frac{dI}{dt} = \beta S I - \gamma I = I (\beta S - \gamma)$$

- **Типові параметри:**
  * $\beta = 0.5$: Швидкість передачі.
  * $\gamma = 0.2$: Швидкість одужання.

---

# II. Нелінійна механіка та фізичні коливання

---

### 5. Осцилятор Ван дер Поля
$$\frac{dx}{dt} = y$$
$$\frac{dy}{dt} = \mu (1 - x^2) y - x$$
- **Феноменологія:** Має стійкий граничний цикл релаксації.

### 6. Загасаючий нелінійний маятник
$$\frac{d\theta}{dt} = \omega$$
$$\frac{d\omega}{dt} = -\frac{g}{L} \sin(\theta) - \gamma \omega$$
- **Феноменологія:** Показує стійкі фокуси у стані спокою та нестійкі сідла в перевернутих положеннях.

### 7. Автономний осцилятор Дуффінга
$$\frac{dx}{dt} = y$$
$$\frac{dy}{dt} = - \delta y - \beta x - \alpha x^3$$
- **Феноменологія:** Бістабільна система з потенціалом з двома ямами.

# III. Математичні основи та якісна теорія

---

### 8. Класичний pplane (Полкінг)
$$\frac{dx}{dt} = 2x - y + 3(x^2 - y^2) + 2xy$$
$$\frac{dy}{dt} = x - 3y - 3(x^2 - y^2) + xy$$

### 9. Еталонна лінійна система
$$\frac{dx}{dt} = a x + b y$$
$$\frac{dy}{dt} = c x + d y$$
- **Спектральна класифікація:** На основі Сліду та Визначника матриці Якобі.

### 10. Динаміка любові (Строгац)
$$\frac{dx}{dt} = a x + b y$$
$$\frac{dy}{dt} = c x + d y$$
- **Феноменологія:** Лінійна система, що представляє взаємну прихильність Ромео і Джульєтти.
