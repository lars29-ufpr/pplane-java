# pplaneX — Качествен и числен анализ на 2D автономни системи

🌍 **Езици:** [English](README.md) | [Português](README_pt_BR.md) | [Español](README_es.md) | [Français](README_fr.md) | [Русский](README_ru.md) | [Български](README_bg.md) | [Українська](README_uk.md) | [Български](README_bg.md) | [Українська](README_uk.md)

---

**pplaneX** е модерно, високопроизводително интерактивно настолно приложение, изградено с Java 21 и JavaFX за качествен и числен анализ на двумерни автономни системи от обикновени диференциални уравнения (ОДУ) и равнинни фазови портрети:

$$x' = \frac{dx}{dt} = f(x, y)$$
$$y' = \frac{dy}{dt} = g(x, y)$$

Вдъхновено от класическия образователен инструмент `pplane`, първоначално създаден от John C. Polking (Университет Райс) за MATLAB, **pplaneX** беше преработено от нулата, за да предложи плавно потребителско взаимодействие, адаптивно изобразяване в реално време, непрекъснато изследване чрез панорамиране/мащабиране и универсална междуплатформена поддръжка (Linux, Windows и macOS).

## 📥 Инсталиране и бърз старт

**pplaneX** се разпространява като самостоятелен изпълним JAR файл и изисква **Java 21 (LTS) или по-нова версия**.

Ако нямате инсталирана Java или се нуждаете от ръководство стъпка по стъпка за вашата операционна система (Windows, macOS или Linux), вижте нашите ръководства за инсталиране:
- 🇧🇬 [Ръководство за инсталиране (Български)](INSTALL_bg.md)

### Стартиране на приложението

След като инсталирате Java 21+, стартирайте от терминала:

```bash
java -jar pplaneX.jar
```
