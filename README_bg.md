# pplaneX — Качествен и числен анализ на 2D автономни системи

**pplaneX** е модерно, високопроизводително интерактивно десктоп приложение, създадено с Java 21 и JavaFX за качествен и числен анализ на двуизмерни автономни системи от обикновени диференциални уравнения (ОДУ) и равнинни фазови портрети:

$$x' = \frac{dx}{dt} = f(x, y)$$
$$y' = \frac{dy}{dt} = g(x, y)$$

Вдъхновено от класическия образователен инструмент `pplane`, първоначално създаден от Джон К. Полкинг (Университет Райс) за MATLAB, **pplaneX** е пренаписано от нулата, за да предложи плавно потребителско изживяване, реактивно рендиране в реално време, непрекъснато изследване с мащабиране/панорамиране и универсална кросплатформена поддръжка (Linux, Windows и macOS).

## 📥 Инсталиране и бърз старт

**pplaneX** се разпространява като самостоятелен изпълним JAR файл и изисква **Java 21 (LTS) или по-нова версия**.

Ако нямате инсталирана Java или се нуждаете от ръководство стъпка по стъпка за вашата операционна система (Windows, macOS или Linux), вижте нашите локализирани ръководства за инсталиране:

- 📖 **[Ръководство за инсталиране (Български)](INSTALL_bg.md)**

### Стартиране на приложението

След като инсталирате Java 21+, изпълнете в терминала си:

```bash
java -jar pplaneX.jar
```
