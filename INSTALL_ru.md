# Руководство по установке: pplaneX и dfieldX

Это руководство объясняет, как установить и запустить **pplaneX** и **dfieldX** в Windows, macOS и Linux.

Для этих приложений требуется **Java 21 (LTS)** или более новая версия. Предварительная установка Java не требуется. В этом руководстве предполагается, что Java еще не установлена на вашем компьютере.

---

## 1. Загрузка приложения

Загрузите последнюю версию с GitHub:
- **pplaneX:** https://tinyurl.com/pplanex-ufpr
- **dfieldX:** https://tinyurl.com/difieldx-ufpr

Сохраните загруженный файл `.jar` в таком месте, где вы сможете легко его найти позже, например, на Рабочем столе или в папке «Загрузки».

---

## 2. Windows

### Часть A: Установка Java
1. Откройте веб-браузер и перейдите по адресу: https://adoptium.net/
2. Загрузите **Eclipse Temurin Java 21 LTS** для Windows x64.
3. Запустите загруженный установщик.
4. На экране «Custom Setup» (Пользовательская установка) убедитесь, что включены параметры **«Add to PATH»** (Добавить в PATH) и **«Associate .jar files»** (Связать файлы .jar).
5. Завершите установку.

### Часть B: Проверка и запуск
Откройте командную строку (Command Prompt) и выполните:
```bash
java -version
```
Поддерживается любая версия 21 или выше. Чтобы запустить приложение:
```bash
java -jar pplaneX.jar
```
*(или замените на `dfieldX.jar`)*

---

## 3. macOS

### Часть A: Установка Java
1. Перейдите по адресу https://adoptium.net/
2. Загрузите последнюю версию **Java 21 LTS** для macOS.
   * *Совет:* Выбирайте установщик `.dmg` (например, `jdk-21_macos-x64_bin.dmg` для Mac с процессором Intel или аналог `aarch64` для Apple Silicon M1/M2/M3/M4).
3. Запустите загруженный установщик `.dmg` и следуйте инструкциям на экране.

### Часть B: Организация и запуск (обход Gatekeeper)
macOS включает функцию безопасности, которая блокирует приложения от неустановленных разработчиков. Выполните следующие действия при первом запуске:

1. **Организация:** Для большего порядка переместите загруженные файлы `pplaneX.jar` и `dfieldX.jar` в папку **Программы** (Applications).
2. **Не дважды щелкайте** по файлу `.jar` в первый раз. Если вы это сделаете, macOS покажет предупреждение и не позволит его открыть.
3. Вместо этого **щелкните правой кнопкой мыши** (или Control-клик) по файлу `.jar` и выберите **Открыть** (Open) в контекстном меню.
4. Появится диалоговое окно с просьбой подтвердить действие. Снова нажмите **Открыть**.

*Примечание: Это нужно сделать только один раз. При всех последующих запусках вы можете просто дважды щелкнуть файл `.jar`, чтобы запустить приложение в обычном режиме.*
